# Plickers Math Suite

Bộ ứng dụng trắc nghiệm tương tác hỗ trợ công thức LaTeX, thẻ mã hóa 6-bit (1..40) xoay 4 chiều (A=0°, B=90°, C=180°, D=270°), đồng bộ WebSocket thời gian thực, chấm điểm theo trọng số từng câu, bảng xếp hạng điểm hệ 10, tự động lưu `localStorage`, âm thanh Web Audio API và xuất CSV.

## Khởi chạy nhanh
- **Windows:** Chạy đúp `start.bat`.
- **macOS / Linux:** Chạy `./start.sh`.
